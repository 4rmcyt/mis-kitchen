Platform Overview

Everything a kitchen needs.
Nothing it doesn't.

mis.kitchen replaces printed checklists, group chats, and paper logs with a single app your whole team uses — from the chef setting up the day to the cook closing the station.

✓
Daily Task Lists
Every shift starts with a clear checklist. Opening prep, closing duties, station-specific tasks — all assigned, all visible. Cooks check off tasks in real time, admins see progress live.
📖
Recipe Library
Every recipe in one place, always up to date. Scale ingredients by portion count with a single tap. Step-by-step instructions visible on any phone. No more binders, no more "which version is this?"
👥
Crew Lineup
See who's working today, grouped by station. Know at a glance who's on Grill, who's on Tandoor, who's covering Common — without asking anyone.
📋
End-of-Shift Report
One tap sends a structured report to management: what got done, what didn't, notes for the next shift. Sent automatically by email. No more WhatsApp voice notes.
🌡️
Temperature Logs
Cooks log fridge and station temperatures three times a day directly in the app. Full history available for every station — no more paper logs on clipboards.
⏱
Kitchen Timers
Multiple named timers running simultaneously. Set a timer for the lamb, another for the sauce — each with a label, countdown, and audio alert when done.
🔔
Push Notifications
Admins can push instant messages to the whole team or specific stations — even when the app is in the background. Critical updates land on every cook's phone immediately.
📅
Day Templates
Build reusable task templates for different service types — lunch, dinner, deep clean. Apply a template to any day in seconds and start the shift already set up.
Two Roles

Built for both sides
of the pass.

Chefs and managers get full control. Cooks get a clean, fast interface with only what they need for their shift.

Chef / Manager
  • Build and manage task templates for any service type
  • Assign tasks to specific stations or the whole team
  • Manage recipes — add, edit, delete, organize by station
  • Manage the team: invite cooks, set stations and roles
  • Send push notifications to everyone or by station
  • View end-of-shift reports from every cook
  • See full temperature log history for any station
Cook
  • Open the app and see today's tasks — nothing else to figure out
  • Check off tasks as they're done, leave comments if needed
  • Look up any recipe, scale portions on the spot
  • See who's working today and on which station
  • Log fridge temperatures without hunting for a clipboard
  • Run multiple timers while working the line
  • Send end-of-shift report in one tap
